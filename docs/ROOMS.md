# Room authoring guide

Rooms are the data-driven content layer of the generator. Any datapack (or this
mod's own resources) can add rooms; no Java required.

## Anatomy of a room

A room fills a grid cell's interior. Two sizes exist:

- **Single-cell** (`"cells": 1`, default): up to **7 wide x 4 tall x 7 deep**.
- **Big** (`"cells": 2`): up to **15 wide x 12 tall x 15 deep**, covering a 2x2
  block of cells. Big rooms anchor on even cell coordinates (exactly one chunk),
  and the generator raises the room's ceiling to sit just above the template's
  height, so a 12-tall template gets a 12-tall space. Add your own lighting;
  ceiling panels are too far up to light the floor.

The base generator still provides the carpet floor below, the ceiling/lights
above, and the boundary walls and doorways around the room. The template only
describes the interior volume. Keep the area near cell centers walkable,
since world spawn picks a cell center.

Two files define a room:

1. **Structure NBT** at `data/<ns>/structure/<path>.nbt`: a vanilla structure
   template. Author it in-game: build the interior inside a 7x4x7 frame, save it
   with a structure block, and copy the file out of the world's `generated/`
   folder. (The placeholder rooms are generated by `tools/make_placeholder_rooms.py`.)
2. **Registry JSON** at `data/<ns>/backrooms_rooms/<name>.json`:

```json
{
  "template": "noclip:rooms/my_room",
  "weight": 4,
  "cells": 1
}
```

`weight` is relative selection weight within the room's size pool (default 1);
`cells` is 1 or 2 (default 1). Single-cell and big rooms roll separately.
Set `"suppress_generated_lights": true` for dark or custom-lit rooms; the
generator will leave out its usual cell-center fluorescent ceiling panels.

Big rooms may also set `"doors": N` (1-8): the room's outer boundary becomes
solid wall except exactly N doorways, at seeded positions among the 8 perimeter
segments. Use this for authored set pieces (an office suite, a vault) that
should have controlled entrances instead of whatever the maze provides. The
template is responsible for its interior being reachable from every side,
since any perimeter segment can host a door.

## Semantics

- `structure_void` blocks in the template mean "leave the base generator's
  output alone" (i.e., air interior). Explicit `minecraft:air` also clears.
- Block entities work: a chest saved with a `LootTable` tag keeps it, so loot
  rooms are pure data.
- Selection is seeded and deterministic per world seed: ~12.5% of cells roll a
  single-cell room; ~11% of even-aligned 2x2 cell blocks roll a big room (big
  wins; the covered cells skip their single-cell rolls). Warehouse zones spawn
  no rooms.
- Load order is sorted by resource id, so generation is stable across restarts
  regardless of datapack order.

## Compat patches

Ship rooms for other mods in your own namespace and gate the JSON with NeoForge
conditions so they vanish when the target mod is absent:

```json
{
  "neoforge:conditions": [{ "type": "neoforge:mod_loaded", "modid": "create" }],
  "template": "mypack:rooms/create_workshop",
  "weight": 2
}
```

(Condition support is planned; entries load unconditionally right now.)

## Current limits (roadmap)

- Sizes are 1x1 and 2x2 cells only; freeform placement is planned. Rooms spawn
  in a random rotation (seeded per cell), so avoid designs that assume a fixed
  orientation relative to doors.
- No per-level pools yet: every room goes into the Level 0 pool.
